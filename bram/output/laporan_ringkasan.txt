3. METODOLOGI DBSCAN
======================================================================
  DBSCAN: Density-Based Spatial Clustering of Applications with Noise
  Prinsip: Titik yang terisolasi (jauh dari klaster padat) = Noise = Anomali

  Definisi: Anomaly = DBSCAN label -1 (noise point)
  Prediksi : label -1 -> predicted_anomaly = 1 (Anomali/Krisis)
             label >= 0 -> predicted_anomaly = 0 (Normal)

  Anomaly Score: Jarak minimum ke core point terdekat, dinormalisasi [0,1]
                 Score = 1 -> paling jauh/paling anomali

  Tuning Parameter:
  - eps  : Kneedle Algorithm (max perpendicular distance ke diagonal)
  - min_samples = 9 (Global) / 3 (Per-Negara)

  [A] DBSCAN GLOBAL
      Input : data_pca.csv (9 komponen PCA, standarisasi ulang)
      eps   : 3.1631 (otomatis via Kneedle)
      Tujuan: Temukan pasangan (negara, tahun) yang anomali secara global

  [B] DBSCAN PER-NEGARA
      Input : data_scaled.csv (14 fitur, z-score)
      eps   : Adaptif per negara (Kneedle, min 1.0)
      Tujuan: Temukan tahun abnormal dalam sejarah setiap negara

7. KETERBATASAN DAN CATATAN
======================================================================

  1. DBSCAN tidak dirancang untuk deteksi anomali berlabel - kinerja
     terbatas wajar untuk unsupervised learning.

  2. Ground truth IMF mencakup krisis yang berlangsung bertahun-tahun
     (multiyear), sehingga banyak tahun di tengah periode krisis
     mungkin tidak menunjukkan tanda ekstrem di indikator tahunan.

  3. Beberapa negara (SGP, IRL, NLD) memiliki struktur ekonomi unik
     sehingga krisis mereka tidak terpola di ruang fitur yang sama.

  4. Imputasi 25% missing pada Broad_Money_Growth dapat mempengaruhi
     deteksi untuk negara dengan data awal terbatas.

  5. eps dipilih otomatis - optimasi manual mungkin meningkatkan kinerja.

8. KESIMPULAN
======================================================================

  DBSCAN sebagai metode unsupervised learning mampu mendeteksi anomali
  makroekonomi dengan performa yang bervariasi antar pendekatan:

    Terbaik untuk menangkap krisis yang benar-benar ekstrem global.

  * Per-Negara : Lebih seimbang (F1=0.354, AUC=0.638).
